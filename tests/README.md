# Intake form test suite

Run from the `CCW-Intake-Form` directory:

```powershell
npm test
```

Run with Node's built-in coverage report:

```powershell
npm run test:coverage
```

The tests use Node's built-in test runner and require no package installation. They cover form modes, multi-bike limits, Express service calculations, input formatting, acknowledgments, submission payloads, frontend API behavior, and critical HTML/CSS contracts.
